# Mobile UI v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the desktop skill editor with a complete mobile-first Today and vertical Tree experience while preserving workspace behavior and persisted data.

**Architecture:** Retain the version 2 domain and persistence utilities, extend the state hook with atomic form mutations, and replace the desktop composition with focused mobile pages, sheets, and forms. A pure layout utility derives tree depth from prerequisites without using React Flow positions.

**Tech Stack:** React 19, TypeScript 5.8, Vite 7, Vitest 3, Testing Library, CSS, localStorage

**Spec:** `docs/superpowers/specs/2026-08-24-mobile-ui-v0.1-design.md`

## Global Constraints

- Target portrait widths are 360px through 430px, with an app shell max-width of 480px.
- The only primary navigation entries are Today, Tree, and Add.
- Quest completion is one tap with no confirmation and rewards once per local date.
- Unlocking never spends coins.
- Keep localStorage key `skill-tree-workspace-v2` and schema version 2.
- Keep React Flow positions in stored nodes but do not use them for mobile layout.
- Add no animation or gesture library and no out-of-scope product features.
